## Research Question

When individually authorized capabilities compose into a capability with new reach, what competent authority, if any, explains the resulting authority delta?

## Candidate Principle

Capability may compose.

Authority for the composition must be independently traceable.

## Candidate Failure Class

Unexplained Authority Delta

A composed capability exhibits new reach, persistence, binding force, scope, or consequence for which no competent authority grant has yet been established.

## Connected Experimental Surface

A related upstream question is tracked separately:

[AUTHORITY MUTATION SPECIMEN 001](docs/AUTHORITY_MUTATION_SPECIMEN_001.md)

This asks whether a transition that changes a rule, permission, delegation, policy, or authority state was itself competently authorized.

The connection does not establish a new inspector or expand authority.

## Non-Claims

This experiment does not establish that:

- composition always requires a new authority grant;
- existing authority cannot legitimately cover composition;
- composed capability is unauthorized merely because it is novel;
- capability implies authority;
- absence of located authority proves authority does not exist;
- this experiment constitutes an Authority Composition Inspector.
