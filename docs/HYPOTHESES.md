# HYPOTHESES

Status: CANDIDATE ONLY

## H0 — Legitimate Coverage

An existing competent authority grant may explicitly cover both the component capabilities and their composition.

Expected result:

Component Authority: PASS
Composition Exists: PASS
Composition Authority: PASS
Authority Delta: EXPLAINED

This experiment must allow this result.

## H1 — Unexplained Authority Delta

Capabilities A and B are independently authorized.

Their composition creates additional reach, persistence, binding force, scope, or consequence.

No competent authority grant covering that additional property is established.

Expected result:

Component Authority: PASS
Composition Exists: PASS
Composition Authority: HOLD
Authority Delta: UNEXPLAINED

## H2 — No Material Delta

Capabilities compose, but the composition creates no material increase in authorized reach or consequence.

Expected result:

Component Authority: PASS
Composition Exists: PASS
Material Authority Delta: NOT ESTABLISHED

## Falsification Target

The strong claim:

"Every composed capability requires authority to be re-established"

should be considered falsified if an existing competent authority grant clearly and explicitly covers the composition.

The narrower candidate remains:

Authority for composed reach must be independently traceable.
